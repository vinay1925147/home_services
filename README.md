# Home Services Web Application

A full-stack Home Services platform built using the MERN stack. This project helps users book trusted home service professionals such as plumbers, electricians, carpenters, cleaners, doctors, and more through an easy-to-use web interface.

## 🚀 Features

- User Registration & Login
- Secure Authentication
- Browse Multiple Home Services
- Book Service Professionals
- Admin Dashboard
- Manage Users & Bookings
- Responsive Design
- Fast and User-Friendly Interface

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
